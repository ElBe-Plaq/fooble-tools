A set of small web tools. Included are a QR code generator, a barcode generator, a CSS gradient generator, a password
generator, a Roman numeral converter and a time zone converter.

## Pages

- `qr-code.html`
- `barcode.html`
- `css-gradient.html`
- `password.html`
- `roman-numeral.html`
- `timezone.html`
